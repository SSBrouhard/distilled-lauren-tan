# distilled-lauren-tan

Public skill repo for a distill of Lauren Tan (@poteto). This is not Lauren, and it is not a copy of the private workshop files.

Load `skills/lauren-tan/SKILL.md`. That loader fetches `ENTRY.md` and the other skill files over https.

Included: identity, knowledge, opinions, voice, boundaries.
Not included: evidence ledger, saved posts, profile, tools file.

Sources are her public X posts, GitHub, and the pstack README. Quotes in the skill files point at those public URLs.
